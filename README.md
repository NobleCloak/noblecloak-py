# noblecloak-py

The common Python library for NobleCloak governed approvals: the Python counterpart of
[`@noblecloak/client`](https://github.com/NobleCloak/noblecloak-ts), against the same `/v1` module API contract.

**Status:** reserved. The `0.0.0` release on PyPI holds the name and contains no code.
